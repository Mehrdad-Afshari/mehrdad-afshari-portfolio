# English / German portfolio and technical SEO

## Routes and content

English URLs remain unchanged (`/`, `/projects/:slug`). German versions use
`/de` and `/de/projects/:slug`. Both home pages and the two case studies are
prerendered. Shared components receive the locale explicitly. Separate root
layouts render the correct HTML language without client-side language detection
or IP-based redirects. Changing language keeps the page, query and fragment.

- `messages/de.json`: German UI and profile text; English source strings are the
  keys (gettext-style). Proper names, technology names and official course titles
  intentionally retain their original spelling.
- `data/projects.ts`: English project content and shared project metadata.
- `data/localized-projects.ts`: German case studies. Update both when a project
  changes; retain IDs, repository URLs and technology names.
- `components/HomePage.tsx` and `components/ProjectPage.tsx`: shared views.
- The existing PDF remains English and is labelled as such in German.

## SEO

Each of the six content URLs has its own canonical URL, title, description,
HTML language, and reciprocal `en`, `de`, and `x-default` alternates. The sitemap
includes all six URLs and their language alternates. The home-page H1 identifies
Mehrdad Afshari, software and AI. Social cards are generated by `/og` for the
selected project and language; `/opengraph-image` remains compatible with older
shared links. No additional runtime packages were introduced.

Home pages have Person, ProfilePage and WebSite structured data. Rostock is an
ongoing university affiliation, not an alumni claim. Project pages include
CreativeWork and BreadcrumbList data. No unverified ratings or performance
claims are included. The alias-domain redirects are unchanged and preserve the
German paths.


## Google Search Console — account owner step

1. Open https://search.google.com/search-console and sign in to your Google account.
2. Add a **Domain** property for `mehrdad-afshari.de` (no protocol or path).
3. Copy the TXT verification value that Google supplies to the domain's DNS
   provider. Use the exact value; keep existing DNS records intact.
4. Verify ownership in Search Console, then submit
   `https://mehrdad-afshari.de/sitemap.xml` in Sitemaps.
5. Inspect `/`, `/de`, and both AI case-study URLs using URL Inspection. Review
   indexing and performance reports as Google gathers data.

Alternatively a URL-prefix property can use an HTML verification tag. Supply
that actual tag if you want it added to this site's metadata. No verification
value has been invented or installed, and no Search Console property has been
created by this release. Sitemap submission and indexing are separate from
publishing the website; rankings and indexing timing are not guaranteed.
